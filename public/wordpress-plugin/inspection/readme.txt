إضافة Inspaction من تطوير Ox Tech - Ahmed Gaber لربط موقع شركة Safero مع نظام الـ ERP وعرض شهادات الفحص الشامل وتقارير المعايرة داخل إطار متجاوب (iFrame).

== Description ==
هذه الإضافة تتيح لزوار موقع شركة Safero وللعملاء الذين يقومون بمسح كود الـ QR المطبوع على شهاداتهم، فتح صفحة مخصصة في موقع ووردبريس تعرض شهادتهم الرسمية فوراً داخل إطار فريم أنيق ومتجاوب، مع إمكانية التحميل والطباعة.

== المميزات الرئيسية ==
* **اسم الإضافة:** Inspaction
* **المطور:** Ox Tech - Ahmed Gaber
* **الدعم التلقائي للـ QR كود:** بمجرد مسح كود الـ QR، يتم تمرير رقم الشهادة في الرابط وتفتح الشهادة تلقائياً داخل الفريم.
* **محرك بحث فوري:** إذا فتح العميل الصفحة مباشرة، يظهر له صندوق بحث بهوية Safero لإدخال رقم الشهادة وعرضها فوراً.
* **خيارات تحكم كاملة:** ضبط رابط نظام الـ ERP (الـ Subdomain) وارتفاع إطار العرض بسهولة من لوحة تحكم ووردبريس.

== طريقة التثبيت ==
1. قم بتنزيل ملف الإضافة المضغوط `inspection.zip`.
2. من لوحة تحكم ووردبريس اذهب إلى: **إضافات (Plugins)** -> **أضف إضافة جديدة (Add New)** -> **رفع إضافة (Upload Plugin)**.
3. اختر ملف `inspection.zip` ثم اضغط **تنصيب الآن** ثم **تفعيل**.
4. ستظهر قائمة جديدة في لوحة التحكم باسم **Inspaction**: أدخل فيها رابط نظام الـ ERP (مثال: `https://erp.safero-eg.com`).
5. أنشئ صفحة جديدة في ووردبريس وسمّها **التحقق من الشهادات** وضع بداخلها الشورت كود:
   `[inspection_certificate]`
