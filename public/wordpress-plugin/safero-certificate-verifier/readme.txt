إضافة رسمية متكاملة لربط موقع شركة سافيرو (Safero Services & Consultations) مع نظام الـ ERP للتحقق الفوري من شهادات التدريب المعتمدة وشهادات فحص معدات الرفع وشهادات ISO المعتمدة، مع دعم كامل للفريم المباشر (Iframe) والتضمين التلقائي بمجرد مسح رمز الـ QR بالهاتف.

== Description ==
تربط هذه الإضافة موقع شركة Safero الرئيسي بنظام الـ ERP عبر REST API آمن وفوري.

المميزات الأساسية:
* **دعم شامل للنوعين**: التحقق من شهادات التدريب (أكاديمية سافيرو) وشهادات فحص معدات الرفع (LOLER / ISO).
* **دعم الفريم المباشر (Embedded Iframe)**: عرض شكل الشهادة الرسمية الأصلية في إطار متجاوب مباشرة داخل موقعك.
* **دعم مسح الـ QR التلقائي**: عند مسح رمز الـ QR من الشهادة المطبوعة (مثال: `?cert=2026101001`)، تفتح صفحة موقع الشركة ويتم جلب الشهادة وعرضها فوراً بدون أي نقرة إضافية.
* **زر تحميل PDF رسمي**: تحميل مباشر للنسخة المعتمدة والمختومة من الـ ERP بضغطة زر.
* **مرونة الإدخال**: تدعم أرقام الشهادات بكافة الصيغ (مع أو بدون بادئة `SAF/`).

== الشورت كود المتاح (Shortcodes) ==

1. الشورت كود العام (تدريب + فحص):
`[safero_certificate_verifier]`

2. شورت كود فريم شهادة التدريب التفاعلي:
`[safero_certificate_frame]`
(يقرأ رقم الشهادة تلقائياً من الرابط `?cert=...` ويعرض الفريم المباشر فوراً).

3. شورت كود مخصص لشهادات التدريب فقط:
`[safero_training_certificate_verifier]`

== Installation ==
1. انسخ مجلد الإضافة إلى `wp-content/plugins/safero-certificate-verifier/` أو ارفعه كملف zip من لوحة تحكم ووردبريس.
2. فعّل الإضافة.
3. من لوحة التحكم، اذهب إلى: **الإعدادات** -> **شهادات Safero ERP**.
4. اضبط رابط نظام الـ ERP (مثال: `https://safero.oxtech.uk` أو `http://localhost:8000`).
5. أنشئ صفحة جديدة باسم "التحقق من الشهادات" أو "شهادة" وضع بداخلها:
   `[safero_certificate_verifier]`
